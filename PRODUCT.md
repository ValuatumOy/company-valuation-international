# Product

## Platform

web

## Product Purpose

Valuatum's international company-valuation website explains valuation methods and provides reviewed report examples. Finnish orders go to arvonmaaritys.fi. The user confirmed on 14 October 2026 that Danish companies should use the same automatic ordering and forecast-review pipeline, with English reports and DKK financial figures.

## Operating Context

Visitors select a company, pay for a report, review and edit forecasts, start generation, and read or download the result. Existing international enquiries remain available. The company-valuation.com domain has not been switched to this build; public Vercel previews remain noindex.

## Capabilities and Constraints

Country, legal entity, identifier, currency and data source must remain bound through payment and report generation. Checkout currency and report currency are separate. Danish automatic ordering stays unavailable until its source, forecast handling and payment configuration are verified. Report examples retain explicit sources and forecast assumptions. Do not fabricate peer data, customer proof or missing financial history.

## Brand Commitments

Extend the existing website identity and plain English voice. Preserve the Finnish service's separate ordering destination.

## Evidence on Hand

Reviewed Finnish examples: Harvia, Gofore and Fiskars. English JYSK example. NVIDIA uses official FY2026 accounts and manually authored illustrative forecasts. Its full report replaces the earlier short example only after financial and visual review.
